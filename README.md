# Stock-Analysis-and-Portfolio-Optimization 

This project leverages Python to analyze historical stock data and perform portfolio optimization. It uses the `yfinance` library to fetch stock data for multiple companies, visualizes trends like closing prices, moving averages, and daily returns, and builds an efficient frontier for portfolio optimization. Key features include moving average calculations, portfolio simulation, and performance metrics like Sharpe ratio, all aimed at identifying optimal stock allocations for maximum return-to-risk ratio.
